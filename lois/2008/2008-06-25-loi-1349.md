# Loi n° 1.349 du 25 juin 2008 modifiant le livre premier du Code pénal

## Article 1er

> Voir les articles 4-1 à 4-4 du Code pénal.

## Article 2

> Voir les articles 29-1 à 29-8 du Code pénal.
