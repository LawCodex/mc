# Ordonnance Souveraine du 23 avril 1923 concernant les insignes de l'ordre de Saint-Charles

Vu l'ordonnance du 16 janvier 1863 ;

## Article 1er

La rosette de Notre ordre de Saint-Charles, lorsqu'elle sera portée à la boutonnière, sera fixée :

Pour les grands-croix de l'ordre, sur ruban d'or ;

Pour les grands-officiers, sur ruban mi-partie or, mi-partie argent ;

Pour les commandeurs, sur ruban d'argent.
