# Communiqué n° 2008-05 du 28 avril 2008 de la Direction du Travail relatif au S.M.I.C. Salaire Minimum Interprofessionnel de Croissance applicable à compter du 1er mai 2008

Il est porté à la connaissance des partenaires sociaux que, dans la région économique voisine à laquelle fait référence la loi n° 739 du 16 mars 1963, modifiée par la loi n° 1.068 du 28 décembre 1983, le S.M.I.C. a été revalorisé à compter du 1er mai 2008.

Cette revalorisation est intervenue comme indiqué dans les barèmes ci-après :

| **Taux horaire** | | | |
| Âge | Normal | + 25 % | + 50 % |
| + de 18 ans | 8,63 euro(s) | 10,78 euro(s) | 12,94 euro(s) |
| + de 17 à 18 ans | 7,76 euro(s) |  |  |
| de 16 à 17 ans | 6,90 euro(s) |  |  |

| **Taux hebdomadaire (SMIC horaire X 39 h)** | |
| Âge | Normal |
| + de 18 ans | 336,57 euro(s) |
| + de 17 à 18 ans | 302,64 euro(s) |
| de 16 à 17 ans | 269,10 euro(s) |

| **Taux hebdomadaire (SMIC horaire X 39 h)** | |
| + de 18 ans | 336,57 euro(s) |
| + de 17 à 18 ans | 302,64 euro(s) |
| de 16 à 17 ans | 269,10 euro(s) |

| **Taux mensuel (SMIC mensuel X 169 h)** | |
| + de 18 ans | 1.458,47 euro(s) |
| + de 17 à 18 ans | 1.311,44 euro(s) |
| de 16 à 17 ans | 1.166,10 euro(s) |

| **Avantages en nature** | | |
| Nourriture | Logement |  |
| 1 repas | 2 repas | 1 mois |
| 3,28 euro(s) | 6,56 euro(s) | 65,60 euro(s) |

Il est rappelé que, conformément aux dispositions de l'article 2 de l'arrêté ministériel n° 63-131 du 21 mai 1963 fixant les taux minima des salaires, les rémunérations minimales doivent être majorées d'une indemnité exceptionnelle de 5 % de leur montant. Cette indemnité ne donne pas lieu aux versements et aux retenues prévus au titre de la législation sociale et de la législation sur les accidents du travail et les maladies professionnelles.
