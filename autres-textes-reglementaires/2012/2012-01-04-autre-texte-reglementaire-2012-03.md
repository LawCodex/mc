# Communiqué n° 2012-03 du 4 janvier 2012 relatif au S.M.I.C. Salaire Minimum Interprofessionnel de Croissance applicable à compter du 1er janvier 2012

Il est porté à la connaissance des partenaires sociaux que, dans la région économique voisine, le S.M.I.C. a été revalorisé à compter du 1er janvier 2012.

Cette revalorisation est intervenue comme indiqué dans les barèmes ci-après :

| **Taux horaire** | | | |
| Âge | Normal | + de 25 % | + de 50 % |
| + de 18 ans | 9,22 euro(s) | 11,52 euro(s) | 13,83 euro(s) |
| + de 17 à 18 ans | 8,29 euro(s) |  |  |
| de 16 à 17 ans | 7,37 euro(s) |  |  |
| **Taux hebdomadaire (SMIC horaire X 39h)** | | | |
| + de 18 ans | 359,58 euro(s) |  |  |
| + de 17 à 18 ans | 323,31 euro(s) |  |  |
| de 16 à 17 ans | 287,43 euro(s) |  |  |
| **Taux mensuel (SMIC mensuel X 169 h)** | | | |
| + de 18 ans | 1.558,18 euro(s) |  |  |
| + de 17 à 18 ans | 1.401,01 euro(s) |  |  |
| de 16 à 17 ans | 1.245,53 euro(s) |  |  |
| **Avantages en nature** | | | |
| Nourriture | Logement |  |  |
| 1 repas | 2 repas | 1 mois |  |
| 3,44 euro(s) | 6,88 euro(s) | 68,80 euro(s) |  |

Il est rappelé que, conformément aux dispositions de l'article 2 de l'arrêté ministériel n° 63-131 du 21 mai 1963 fixant les taux minima des salaires, les rémunérations minimales doivent être majorées d'une indemnité exceptionnelle de 5 % de leur montant. Cette indemnité ne donne pas lieu aux versements et aux retenues prévus au titre de la législation sociale et de la législation sur les accidents du travail et les maladies professionnelles.
