# Circulaire n° 2022-11 du 2 août 2022 relative au S.M.I.C. Salaire Minimum Interprofessionnel de Croissance applicable à compter du 1er août 2022

Il est porté à la connaissance des partenaires sociaux que, dans la région économique voisine, le S.M.I.C. a été revalorisé à compter du 1er août 2022.

Cette revalorisation est intervenue comme indiqué dans les barèmes ci-après :

| **Taux horaire** | | | |
| Age | Normal | + 25 % | + 50 % |
| + de 18 ans | 11,07 euro(s) | 13,84 euro(s) | 16,61 euro(s) |
| + de 17 à 18 ans | 9,96 euro(s) |  |  |
| de 16 à 17 ans | 8,86 euro(s) |  |  |
| **Taux hebdomadaire (SMIC horaire x 39 h)** | | | |
| + de 18 ans | | 431,73 euro(s) | |
| + de 17 à 18 ans | | 388,44 euro(s) | |
| de 16 à 17 ans | | 345,54 euro(s) | |
| **Taux mensuel (SMIC mensuel x 169 h)** | | | |
| + de 18 ans | | 1.870,83 euro(s) | |
| + de 17 à 18 ans | | 1.683,24 euro(s) | |
| de 16 à 17 ans | | 1.497,34 euro(s) | |
| **Avantages en nature** | | | |
| Nourriture | | Logement | |
| 1 repas | 2 repas | 1 mois | |
| 3,86euro(s) | 7,88 euro(s) | 78,80 euro(s) | |

Il est rappelé que, conformément aux dispositions de l'article 2 de l'arrêté ministériel n° 63-131 du 21 mai 1963 fixant les taux minima des salaires, les rémunérations minimales doivent être majorées d'une indemnité exceptionnelle de 5 % de leur montant. Cette indemnité ne donne pas lieu aux versements et aux retenues prévus au titre de la législation sociale et de la législation sur les accidents du travail et les maladies professionnelles.
