# Circulaire n° 2019-16 du 27 décembre 2019 relative au S.M.I.C. Salaire Minimum Interprofessionnel de Croissance applicable à compter du 1er janvier 2020

Il est porté à la connaissance des partenaires sociaux que, dans la région économique voisine, le S.M.I.C. a été revalorisé à compter du 1er janvier 2020.

Cette revalorisation est intervenue comme indiqué dans les barèmes ci-après :

| **Taux horaire** | | | |
| Age | Normal | + 25 % | + 50 % |
| + de 18 ans | 10,15 euro(s) | 12,69 euro(s) | 15,22 euro(s) |
| + de 17 à 18 ans | 9,13 euro(s) |  |  |
| de 16 à 17 ans | 8,12 euro(s) |  |  |
| **Taux hebdomadaire (SMIC horaire x 39 h)** | | | |
| + de 18 ans | | 395,85 euro(s) | |
| + de 17 à 18 ans | | 356,07 euro(s) | |
| de 16 à 17 ans | | 336,68 euro(s) | |
| **Taux mensuel (SMIC mensuel x 169 h)** | | | |
| + de 18 ans | | 1.715,35 euro(s) | |
| + de 17 à 18 ans | | 1.542,97 euro(s) | |
| de 16 à 17 ans | | 1.372,28 euro(s) | |
| **Avantages en nature** | | | |
| Nourriture | | Logement | |
| 1 repas | 2 repas | 1 mois | |
| 3,655euro(s) | 7,30 euro(s) | 73 euro(s) | |

Il est rappelé que, conformément aux dispositions de l'article 2 de l'arrêté ministériel n° 63-131 du 21 mai 1963 fixant les taux minima des salaires, les rémunérations minimales doivent être majorées d'une indemnité exceptionnelle de 5 % de leur montant. Cette indemnité ne donne pas lieu aux versements et aux retenues prévus au titre de la législation sociale et de la législation sur les accidents du travail et les maladies professionnelles.
