# Communiqué n° 2010-16 du 22 décembre 2010 relatif au S.M.I.C. Salaire Minimum Interprofessionnel de Croissance applicable à compter du 1er janvier 2011

Il est porté à la connaissance des partenaires sociaux que, dans la région économique voisine à laquelle fait référence la loi n° 739 du 16 mars 1963, modifiée par la loi n° 1.068 du 28 décembre 1983, le S.M.I.C. a été revalorisé à compter du 1er janvier 2011.

Cette revalorisation est intervenue comme indiqué dans les barèmes ci-après :

| **Taux horaire** | | | |
| Âge | Normal | + 25 % | + 50 % |
| + de 18 ans | 9 euro(s) | 11,25 euro(s) | 13,50 euro(s) |
| + de 17 à 18 ans | 8, 10 euro(s) |  |  |
| + de 16 à 17 ans | 7,20 euro(s) |  |  |
| **Taux hebdomadaire (SMIC horaire X 39 h)** | | | |
| + de 18 ans | 351 euro(s) |  |  |
| + de 17 à 18 ans | 315, 90 euro(s) |  |  |
| + de 16 à 17 ans | 280, 80 euro(s) |  |  |
| **Taux mensuel (SMIC mensuel X 169 h)** | | | |
| + de 18 ans | 1.521 euro(s) |  |  |
| + de 17 à 18 ans | 1.368, 90 euro(s) |  |  |
| + de 16 à 17 ans | 1.219, 80 euro(s) |  |  |
| **Avantages en nature** | | | |
| Nourriture | Logement |  |  |
| 1 repas | 2 repas | 1 mois |  |
| 3,36 euro(s) | 6,72 euro(s) | 67,20 euro(s) |  |

Il est rappelé que, conformément aux dispositions de l'article 2 de l'arrêté ministériel n° 63-131 du 21 mai 1963 fixant les taux minima des salaires, les rémunérations minimales doivent être majorées d'une indemnité exceptionnelle de 5 % de leur montant. Cette indemnité ne donne pas lieu aux versements et aux retenues prévus au titre de la législation sociale et de la législation sur les accidents du travail et les maladies professionnelles.
